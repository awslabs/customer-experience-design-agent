# acxd-platform scope

Full enterprise ACXD platform lifecycle — all 33 core stages plus all 10 ACXD plugin stages. Comprehensive
depth and test strategy for security-conscious, process-driven enterprise customers.

## When to use

- Building a contact centre automation platform that will host multiple use cases
- Platform Lead engagement (single or multiple initial use cases)
- Customer requires full CI/CD pipeline, multi-environment deployment, operational readiness
- The most comprehensive engagement — full AI Velocity Team platform build

## Why these stages

Every stage executes because a platform engagement requires the full lifecycle: business alignment (Ideation +
CX Discovery), technical design (Inception + platform config + flow architecture + backend
design), construction (SDK resources + flow build + backend build), and operationalisation (deployment pipeline
+ operational readiness). No shortcuts — this is enterprise-grade.
