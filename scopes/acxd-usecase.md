# acxd-usecase scope

Focused single use-case delivery — 23 core stages plus 9 ACXD plugin stages. Standard depth and test strategy.
Suitable for standalone use-case delivery or a module within a larger engagement.

## When to use

- Building a single automated customer journey (e.g., bill payment, order status, appointment booking)
- Use-Case Lead engagement — customer wants one specific problem solved
- Subsequent use case on an existing platform (combined with brownfield discovery)
- Focused, single-journey delivery — more involved than a POC, lighter than a full platform build

## Why these stages, why skip those

Skips Market Research, Team Formation, and late Operation stages (environment provisioning, performance
validation, feedback) because a single use case doesn't require platform-level ceremony. Retains CX Discovery
(scoped to one use case), platform config (may be existing), flow design (flow boundaries that keep the conversation together), and deployment.
